
## Rock-Paper-Scissors Game

This is a simple command-line Rock-Paper-Scissors game implemented in Python. It can also be used as a learning foundation for understanding oop in python as the code has been created in oop style with easy to understand class and method naming

## Object-Oriented Programming (OOP) in Python

Key OOP Concepts Used
**Classes:** The code defines classes such as Game and Player to represent the main components of the game. Classes are blueprints for creating objects.

**Objects:** Instances of classes (e.g., a Player object) hold data and provide methods to interact with that data.

**Encapsulation:** Data and related functions are bundled together inside classes, making the code modular and easier to maintain.

**Methods:** Functions defined inside classes (e.g., play() in Game) operate on the data within the object.

**Inheritance**: Allows new classes to inherit properties and methods from existing classes.

### How to Run

1. **Open a terminal** and navigate to the project directory:

2. **Run the game** using Python:
    - powershell
	```
	python src/main.py
	```
    - bash
	```
	python3 src/main.py
	```

### How to Play

- When you run the game, you will be prompted to enter your choice: `r (rock)`, `p (paper)`, or `s (scissors)`.
- Type your choice and press Enter.
- The computer will randomly select its move.
- The winner will be displayed after each round.
- You can play multiple rounds or exit the game as prompted.

Enjoy playing!
